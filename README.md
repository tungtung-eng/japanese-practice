# 日語隨身練

手機網頁 App：旅遊和生活日語會話、五十音複習、每天三句推播。介面沿用「隨身翻譯」的配置，配色改成和風（藍染、朱紅、米白）。

## 功能

- **今日三句**：每天早、中、晚各一句。早上是寒暄、交通，中午是點餐、購物，晚上是飯店、觀光、藥局、緊急狀況，睡前順便複習早、中兩句
- **10 個場景、133 句**：✈️ 機場、🏨 飯店、🍜 餐廳、🚃 交通、🛍️ 購物、🏪 超商、♨️ 觀光溫泉、💊 藥局、🆘 緊急、💬 寒暄。每句都有漢字假名注音、羅馬拼音、中文
- **🔊 發音**：正常速度和 🐢 慢速，用手機內建的日文語音
- **🎤 跟著念日文**：念完後比對，念對的字變綠色、念錯的字變朱紅色，並給分數
- **🔁 自動跟讀**：App 念一句 → 你跟著念 → 自動比對 → 下一句，不用一直按
- **🎤 我說中文**：說中文，App 告訴你日文怎麼說；句庫裡有一樣的句子就直接顯示（有假名注音）
- **⭐ 收藏、📅 今日複習**：收藏的句子、今日三句、念得不好的句子，會照遺忘曲線（1、2、4、7、15、30、60 天後）排進複習
- **あ 五十音**：平假名、片假名、混合；看假名選拼音或反過來；清音、濁音、拗音。常錯的字會比較常出現，也會在五十音表上標紅色
- **🔔 每日三句推播**：台灣時間 09:00、11:30、20:00
- 可以「加入主畫面」當 App 用，沒網路也能看句子、聽發音、練五十音

## iPhone 使用方式

1. 用 **Safari** 打開網址
2. 下方「分享」⬆️ →「**加入主畫面**」
3. 從主畫面的「日語隨身練」圖示打開
4. 按右上角「⚙️ 設定」→「🔔 開啟每日三句」→ 允許通知（需要 iOS 16.4 以上）
5. 語音辨識需要開啟「設定 → Siri」裡的聽寫功能；第一次用麥克風時要按「允許」

## 放到網路上

### 網頁（GitHub Pages）

1. 到 repo 的 **Settings → Pages**
2. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save
3. 約一分鐘後網址是 `https://tungtung-eng.github.io/japanese-practice/`

### 推播伺服器（Cloudflare Worker）

跟工地氣象站用同一個 Cloudflare 帳號。在 Windows 上雙擊 **`部署推播伺服器.bat`**，它會：

1. 檢查 Cloudflare 登入（沒登入會開瀏覽器）
2. 第一次會建立存訂閱資料的 KV，並把 id 寫進 `wrangler.toml`
3. 第一次會產生推播金鑰，存在 `.env`（不會進版本庫；**不要刪**，換金鑰的話已訂閱的手機會收不到）
4. 部署，並上傳金鑰

部署好的網址應該是 `https://japanese-practice-push.qianzhen-site.workers.dev`。如果不一樣，要改 `app.js` 裡的 `PUSH_API`。

第一次部署後，`wrangler.toml` 會多一個 KV 的 id，記得 commit。

## 全部免費

| 功能 | 使用的服務 |
|---|---|
| 發音 | 手機內建（speechSynthesis） |
| 語音辨識 | 瀏覽器內建（Web Speech API） |
| 我說中文 → 日文 | Google 翻譯免費公開端點（附羅馬拼音）；失敗時改用 MyMemory |
| 推播 | Cloudflare Workers 免費方案（排程 3 個、KV 存訂閱） |
| 網頁 | GitHub Pages |

注意：Cloudflare 免費方案每個帳號最多 5 個排程；工地氣象站用 1 個，這裡用 3 個，合計 4 個。

## 本機測試

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

## 檔案

- `index.html` 畫面
- `style.css` 樣式（和風配色，支援深色模式）
- `app.js` 發音、語音比對、複習排程、五十音測驗、推播開關
- `phrases.js` **句子資料**（網頁和推播伺服器共用）。要加句子就改這裡
- `kana.js` 五十音資料
- `sw.js`、`manifest.webmanifest` 加入主畫面、離線使用、收推播
- `worker/` 推播伺服器；`wrangler.toml` 它的設定（排程時間）
- `deploy.ps1`、`部署推播伺服器.bat` 部署推播伺服器

## 加句子

在 `phrases.js` 找到場景，照格式在**那個場景的最後面**加一行（加在中間的話，之後的句子編號會跑掉，收藏和複習紀錄會對到錯的句子）：

```js
['[漢字|かんじ]の[読|よ]み[方|かた]', 'kanji no yomikata', '漢字的讀法'],
```

`[漢字|讀音]` 會變成漢字上方的假名。新句子會自動加入每日三句的輪播。
