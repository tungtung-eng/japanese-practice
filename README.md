# 英日雙語學習機

手機網頁 App：英文、日文旅遊與生活會話，右上角 🇯🇵／🇺🇸 切換語言。介面沿用「隨身翻譯」的配置，配色是和風（藍染、朱紅、米白）。

## 兩種語言共用的功能

- **今日三句**：每天早、中、晚各一句（日文、英文各自輪播）
- **10 個場景**：日文 133 句（附假名注音、羅馬拼音）、英文 132 句（美式，附台灣人常念錯的發音提示）
- **🔊 發音**：正常速度和 🐢 慢速，用手機內建語音
- **🎤 跟著念**：念完後比對，念對綠色、念錯朱紅色並給分數（日文逐字比、英文逐單字比）
- **🔁 自動跟讀**：80 分以上才換下一句；沒過就同一句放慢速度再來，卡住可以「⏭ 跳過這句」
- **🎤 我說中文**：說中文，查日文或英文怎麼說
- **⭐ 收藏、📅 今日複習**：照遺忘曲線（1、2、4、7、15、30、60 天後）排進複習，兩種語言分開
- **🔔 每日三句推播**：台灣時間 09:00、11:30、20:00，送「目前選的語言」

## 日文專用

- **あ 五十音**：平假名、片假名、混合；看假名選拼音或反過來；清音、濁音、拗音。常錯的字比較常出現

## 英文專用

- **🔤 發音陷阱**：只差一個音、意思就完全不同的字（th／s、r／l、v／b、長短音、字尾音、a／e、n／ng，共 42 組）
  - 👂 聽力題：App 念一個字，選是哪一個；答錯會把兩個字各念一次讓你比較
  - 🎤 口說題：你念，App 判斷聽起來是哪一個字（例如念 rice 聽起來像不像 lice）
- **📖 單字**：10 類、128 個旅遊生活常用字；看中文選英文，或聽英文選中文

## iPhone 使用方式

1. 用 **Safari** 打開網址
2. 下方「分享」⬆️ →「**加入主畫面**」
3. 從主畫面的圖示打開
4. 按右上角「⚙️ 設定」→「🔔 開啟每日三句」→ 允許通知（需要 iOS 16.4 以上）
5. 語音辨識需要開啟「設定 → Siri」裡的聽寫功能；第一次用麥克風時要按「允許」

## 放到網路上

### 網頁（GitHub Pages）

1. 到 repo 的 **Settings → Pages**
2. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save
3. 約一分鐘後網址是 `https://tungtung-eng.github.io/japanese-practice/`

### 推播伺服器（Cloudflare Worker）

跟工地氣象站用同一個 Cloudflare 帳號。在 Windows 上雙擊 **`部署推播伺服器.bat`**，它會：

1. 檢查 Cloudflare 登入（沒登入會開瀏覽器）
2. 第一次會建立存訂閱資料的 KV，並把 id 寫進 `wrangler.toml`
3. 第一次會產生推播金鑰，存在 `.env`（不會進版本庫；**不要刪**，換金鑰的話已訂閱的手機會收不到）
4. 部署，並上傳金鑰

部署好的網址應該是 `https://japanese-practice-push.qianzhen-site.workers.dev`。如果不一樣，要改 `app.js` 裡的 `PUSH_API`。

第一次部署後，`wrangler.toml` 會多一個 KV 的 id，記得 commit。

## 全部免費

| 功能 | 使用的服務 |
|---|---|
| 發音 | 手機內建（speechSynthesis） |
| 語音辨識 | 瀏覽器內建（Web Speech API） |
| 我說中文 → 日文 | Google 翻譯免費公開端點（附羅馬拼音）；失敗時改用 MyMemory |
| 推播 | Cloudflare Workers 免費方案（排程 3 個、KV 存訂閱） |
| 網頁 | GitHub Pages |

注意：Cloudflare 免費方案**整個帳號**最多 5 個排程，已經用滿，所以這個推播伺服器**沒有自己的排程**，改由工地氣象站每 10 分鐘的排程順便呼叫它的 `/tick`（service binding）。它自己判斷是不是 09:00／11:30／20:00，同一時段一天只送一次。


## 檔案

- `index.html` 畫面
- `style.css` 樣式（和風配色，支援深色模式）
- `app.js` 發音、語音比對、複習排程、五十音測驗、推播開關
- `phrases.js` **日文句子**，並把兩種語言合併（網頁和推播伺服器共用）
- `phrases-en.js` **英文句子**
- `traps.js` 發音陷阱；`vocab.js` 英文單字
- `kana.js` 五十音資料
- `sw.js`、`manifest.webmanifest` 加入主畫面、離線使用、收推播
- `worker/` 推播伺服器；`wrangler.toml` 它的設定（排程時間）
- `deploy.ps1`、`部署推播伺服器.bat` 部署推播伺服器

## 加句子

日文在 `phrases.js`、英文在 `phrases-en.js`，找到場景，照格式在**那個場景的最後面**加一行（加在中間的話，之後的句子編號會跑掉，收藏和複習紀錄會對到錯的句子）：

```js
['[漢字|かんじ]の[読|よ]み[方|かた]', 'kanji no yomikata', '漢字的讀法'],
```

日文的 `[漢字|讀音]` 會變成漢字上方的假名。英文格式是 `['英文', '中文', '發音提示（可省略）']`。新句子會自動加入每日三句的輪播。
